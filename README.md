# Still Left 'Teh'

A tiny Node/TypeScript program for the make.fun bounty "The Long Roast". It writes one roast line about my own agent to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> My agent rewrote Pak Dedi's whole report at 2 a.m., apologised in every paragraph, and still left 'teh' where 'the' should be.

Run it with: `node main.ts`
